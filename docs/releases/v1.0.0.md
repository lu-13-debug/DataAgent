DataAgent 1.0.0 是面向游戏研发与运营团队的 Windows 数据分析桌面软件。

## 下载与安装

下载下方 **DataAgent-Setup-1.0.0-x64.exe**，双击安装。支持 Windows 10/11 x64，内置运行时，无需安装 Node.js。可选择安装目录并创建桌面和开始菜单快捷方式。

`SHA256SUMS.txt` 提供安装包校验值。GitHub 自动生成的 Source code 压缩包用于开发，安装软件请下载 EXE。

## 功能

- 协作模式支持补充业务背景与关键步骤确认；自动模式连续完成分析。
- 实时显示 8 个 Skill 节点的执行状态、结果摘要和执行记录。
- 导入 CSV/Excel，计算游戏活跃、新增、留存、付费与收入指标。
- 用户自带兼容 Chat Completions 的 API Key，向指定供应商发送业务背景与聚合指标，生成辅助解读。
- 生成完整报告，支持 Markdown 下载与打印/保存 PDF。
- 本机保存数据、报告和额度流水，失败或取消释放冻结额度。

## 当前边界

本版为本地单用户软件，初始 500 试用额度，每次分析使用 20 额度；尚未接入真实支付。模型费用由用户自己的 API 账户承担。API Key 只保留在当前进程内存中，重启后需重新填写。当前开放游戏运营领域和内置工作流。

安装包未配置商业代码签名。首次打开可用演示数据体验；AI 解读需另行配置有效的模型接口与 Key。
