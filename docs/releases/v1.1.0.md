DataAgent 1.1.0 新增云端账号服务。用户可在 Windows 桌面客户端中注册、登录，并使用自己的数据、报告和额度。

## 下载与使用

下载 **DataAgent-Setup-1.1.0-x64.exe**，双击安装，支持 Windows 10/11 x64，无需另装 Node.js。

此安装包是连接云端服务的客户端。首次打开填写管理员部署好的 HTTPS 服务地址；也可以在打包前预置地址。**本次发布提供可部署的软件，没有随安装包提供已经上线的公共账号服务器。** 本机开发允许连接环回 HTTP 地址。

服务运营者可下载本版本 Source code 或克隆仓库，按照 [部署说明](https://github.com/lu-13-debug/DataAgent/blob/v1.1.0/docs/cloud-deployment.md) 使用 Docker Compose/Caddy 部署服务，配置域名、持久化数据卷和可信模型主机。部署后再向用户分发服务地址或预置好的客户端。

## 新增

- 真实用户名/密码注册登录、退出、修改密码；登录会话由服务器验证。
- 按账号隔离上传数据、报告、模型配置与试用额度，同一账号可在不同电脑登录。
- 新账号赠送 500 试用额度，单次分析冻结 20，成功结算、失败或取消释放。
- API Key 仅在当前登录会话的云端内存中使用；上传数据与报告保存于所连接服务中。
- 桌面服务连接、地址预置、连接失败处理与切换服务。

原有协作/自动分析、8 个内置 Skill、CSV/Excel、报告导出功能保留。1.0.0 发布历史仍为原本地单用户版本。

## 当前范围

服务端为单实例 SQLite 版本，尚未接入真实支付、邮箱验证码或自助密码找回。安装包未配置商业代码签名。安装包校验值见 `SHA256SUMS.txt`。

## 验证

65 项自动化测试、生产构建、真实浏览器双账号流程及打包后 EXE 的注册、CSV 上传、两种分析模式、账号隔离、报告与切换服务验收通过。模型集成使用可控响应验证，未使用真实收费 Key 联测。当前环境未执行 Docker 或公网部署。
