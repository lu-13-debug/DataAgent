# 界面一致性、阅读体验与首次使用引导

用户已选择 1A、2A、3A。仅使用既有前端栈和接口，保留此前模型修复。

## 已确认产品边界

- 工作空间显示“工作空间 / 游戏运营”，打开领域说明；不实现项目管理。
- 示例报告免费阅读，协作体验是明确标记的只读说明，不创建任务。真实协作分析仍在现有新建弹窗中确认 20 额度。
- 三步清单可持久关闭，帮助中可重开；完成后不自动出现。
- 云端与本地均通过 useAuth 获取运行模式。云端清单以服务 origin、账号 ID 区分，本地单独保存；存储仅限完成布尔标记。

## 修改范围

1. 侧栏通用空间标识、最近分析查看全部、正确 Info 图标、任务空状态。
2. 服务连接、AI 开放、Key 配置与额度分别表达；不足 20 额度时说明原因并禁止提交收费分析。
3. 字号 token：辅助信息至少 11px，正文至少 13px，中文正文行高 1.75；图表坐标/脚注允许 10px。muted/faint 在 bg/paper 上达到 4.5:1。
4. 三步清单：阅读示例报告、上传或选择数据、生成第一份报告；已有数据/真实完成报告可证明相应进展。说明只读和真实运行的区别。
5. 示例报告标识、数据源加载示例入口、帮助重看清单与协作流程说明。
6. App 根部 ErrorBoundary，提供重新载入与复制诊断；诊断仅含固定错误码、版本、受控异常类型、时间，不含原始 message/stack、URL、状态或 Key。

## 保留与验证

API 契约、服务端分析/额度逻辑、按账号隔离、Key 不落盘、模型白名单不变。保留 skip-link、焦点陷阱、aria-live、减弱动画与打印规则。CSS 先格式化并比较 AST，再改字体和布局。验证包含 cloud/local、AI 未开放/无 Key/额度不足、空任务、持久关闭/帮助重开/跨账号、样式断点与打印。最终必须通过 npm test 和 npm run build。
