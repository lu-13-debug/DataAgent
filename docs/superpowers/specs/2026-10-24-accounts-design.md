# DataAgent 云端账号版设计

用户已选择：保留可下载安装的 Windows 客户端，采用云端统一账号、按账号隔离数据与额度，先完成可部署版本并在本机验收。当前没有可供部署的服务器。

## 用户流程

管理员部署一个 DataAgent 服务，配置 HTTPS 域名。桌面端连接该服务（可在分发时预置地址）；首次使用注册用户名、显示名称和密码。登录后使用现有分析工作台、上传数据、模型设置、报告与额度。用户可修改密码、退出；换电脑连接同一服务登录同一账号仍可看到自己的资料。

用户名为 3–32 个英文字母、数字或下划线，不区分大小写；显示名称支持中文，1–40 字；密码为 10–128 字符，不做静默截断。首版不依赖邮件服务，不包含邮箱验证码、找回密码或真实支付。

## 服务边界

- 新增 createCloudApp 与独立 cloud-index 启动入口。原本 localhost 单用户入口保持可用，现有指标与工作流复用。
- 账号库单独保存密码散列与会话散列；各用户工作空间保存在服务数据目录 users/随机用户ID/ 下。客户端不能指定这个用户 ID，身份只取服务器会话。
- 新账号独立赠送 500 试用额度；分析冻结 20，成功结算，失败/取消释放。任务与额度计算都在服务端执行，不接收客户端上报的扣费或任务完成状态。
- 此部署为单实例、持久化 SQLite 的小规模版本；不宣称支持多副本。活动工作空间与请求并发有上限，防止无限打开数据库。无服务器时本机验证不等同公网已上线。

## 凭据与请求

- 密码用随机盐与异步 scrypt（N=32768,r=8,p=3）散列，比较使用 timingSafeEqual；限制密码计算并发与认证重试。
- 登录生成随机不透明令牌，数据库只存 SHA256 散列。HttpOnly、SameSite=Strict Cookie，生产 HTTPS 添加 Secure；7 天到期。退出撤销当前会话；改密码撤销所有会话。
- 云端写请求检查配置的同源地址，不开放跨站凭据请求；生产启动要求 PUBLIC_URL=https://域名。按 IP/用户名限制注册登录，默认不信任客户端转发头，反向代理环境显式配置。
- API Key 仅在云端当前登录会话的内存里保留，不写账号库、用户库、日志、浏览器存储；退出或重启后需重填。已启动任务会持有原有请求快照直到结束。
- 云端模型地址必须在管理员配置的精确 HTTPS 主机白名单中，禁止自动跟随重定向。未配置白名单时仍可本地确定性计算，但 AI 请求明确不可用。
- 云端上传数据经过 HTTPS 到达该服务并按账号保存；发送模型的是业务背景与聚合指标。UI 与说明明确云端存储、服务会话凭据语义。

## 桌面客户端

客户端通过标准浏览器会话直接加载已验证的云端站点，不在用户电脑启动无鉴权的分析服务。首次未配置时显示本地连接页面，验证目标 /api/runtime 为 DataAgent 云端服务后保存非敏感地址。仅允许 HTTPS；本机开发允许 localhost/127.0.0.1/[::1] 的 HTTP。默认地址可随安装包预置。远程工作台无 Node 权限、无 preload；连接页仅提供验证/保存服务地址的窄接口。切换服务清理原服务会话。

## 验收与交付

测试覆盖注册登录、错误密码、大小写重复账号、Cookie/令牌散列、退出/改密/过期、重启登录、跨账号资源与账本隔离、不同会话 API Key 隔离、跨站写入、限流和模型白名单。浏览器实际注册两个用户，上传专属数据、运行任务、退出切换验证不可见。打包后实际 EXE 连接本机云端服务并完成注册与分析。提供 Dockerfile、Docker Compose、Caddy HTTPS 与部署/备份说明；未执行公网部署时明确说明。
