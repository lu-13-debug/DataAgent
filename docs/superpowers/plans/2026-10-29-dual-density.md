# DataAgent 双密度控制台实施计划

目标：按 P0–P5 建立主题与视图密度两条正交轴，保留现有分析、账号、分享和报告内容。

- [ ] P0：按来源/账号保存外观偏好；系统主题、首帧和 Electron 安全桥接；打印浅色；外观入口。保留既有 API。
- [ ] P1：共享控件与骨架、顶栏和侧栏折叠，保证焦点和移动端可用。
- [ ] P2：工作台、引导、模板与运行面板，紧凑视图保留全部操作。
- [ ] P3：数据源、报告、能力库与额度页面按相同密度规则调整。
- [ ] P4：表格、图表、PNG、打印和弹窗；屏幕主题和浅色导出分离。
- [ ] P5：两主题×两密度、多页面及 390px 视觉、键盘与对比度验收，完整测试和构建。

实现按现有文件增量进行，不覆盖工作区已有改动；现有 CSS 中硬编码颜色要在四组合验收前逐步迁移。当前云端 CSP 禁止内联脚本，与不修改服务端的约束冲突，已向用户提出同源同步脚本或更新 CSP 两种方案，首帧脚本在用户选择后接入。
