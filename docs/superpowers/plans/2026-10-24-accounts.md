# 云端账号版实施计划

> **For agentic workers:** 使用 subagent-driven-development 与 dispatching-parallel-agents，按文件边界并行实现，完成后分别进行规格与质量审查。每个功能先验证失败测试，再实现并复验。

**Goal:** 可下载安装的客户端连接一个支持真实注册登录、隔离用户数据和额度的可部署服务。

**Architecture:** Express 云端入口集中管理 SQLite 账号与随机会话，为认证身份选择现有分析应用工作空间。前端统一登录边界。Electron 作为无 Node 权限的云端桌面客户端。Docker+Caddy 单实例部署。

**Tech Stack:** Node 24、node:crypto、node:sqlite、Express、React/TS、Electron、NSIS、Docker/Caddy。

## 核心回归示例

```js
const alice = await register('alice_qa', 'Alice');
const bob = await register('bob_qa', 'Bob');
assert.equal((await alice.get('/api/bootstrap')).wallet.balance, 500);
const upload = await alice.upload('/api/datasets/upload', privateCsv);
assert.equal((await bob.get('/api/datasets/' + upload.dataset.id)).status, 404);
await alice.post('/api/auth/logout', {});
assert.equal((await alice.get('/api/bootstrap')).status, 401);
```

接受标准以实际接口与打包程序通过为准，不以静态页面、假登录或仅子代理报告判断完成。
