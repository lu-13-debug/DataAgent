# 云端只读分享实施计划

目标：仅 cloud 账号为已完成报告创建可撤销、有限期的只读分享；可隐藏收入相关内容，不暴露原始记录，并统计分享带来的访问和注册。沿用现有账号隔离、CSRF 与白名单；local 不展示虚假分享能力。无新增重量级依赖。

## 设计边界

- 服务端创建随机高熵分享令牌，只存其哈希；URL 在创建时显示一次，分享管理列表只提供非秘密 ID、到期时间、脱敏状态、访问/注册计数及撤销，不回显令牌。失效、过期、被撤销和不存在均为相同不可用响应。仅所有者可管理；分享快照脱离任务原始数据，后续编辑不默默扩大授权范围。
- 用户选择有限有效期与隐藏收入；服务端使用严格白名单生成分享载荷。隐藏收入时移除收入、付费和可能泄漏金额的图表、表格、质量/自由文本与 AI 叙述；仅保留可明确确认的非敏感指标及静态说明，不做关键字过滤式安全承诺。公开分享不提供数据源、玩家 ID、原始 CSV、账号、Key 或内部模型请求。
- 公共 API 独立可匿名访问、no-store、no-referrer、限流和固定数据上限；页面只读，展示生成来源与口径，不提供原始数据下载。公开路由须在认证前处理，管理路由必须现有会话与同源保护。token 不写日志或 third-party，失败响应脱敏。
- 分享访问和注册归因使用站内、去标识化计数；用户从分享页主动注册才携带归因标识。注册服务端验证分享有效，已过期或撤销不归因；提供防重复约束并定义归因口径，不收集 IP/玩家数据或接入第三方跟踪。若无法原子记录注册与归因，明确其统计局限。
- 能力通过可选 runtime capability 和接口兼容扩展声明；cloud/local 测试旧客户端、跨账号、费用不变、失效及敏感信息无泄漏。用户可管理、撤销已有分享，过期默认值明确展示。

## 验收

1. 服务端 RED→GREEN：创建/管理/期限/撤销/匿名访问/跨账号、no-store、非真实数据/Key不泄漏、隐藏收入全面检查、空数据与大量请求边界、注册归因。
2. 浏览器 cloud 只读页面、失效页、管理/撤销、隐藏收入；local 无分享入口；实际匿名用户直接打开链接并注册；无模型调用及额度变化。
3. `npm test`、`npm run build`、浏览器键盘/390px，独立规格与安全质量审查。分享功能尚未公网部署，最终重建并验证 Windows 安装包。
