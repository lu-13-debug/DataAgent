# Windows 桌面体验实施计划

> 基于已批准的分阶段方案，保留现有云端账号客户端、会话隔离与模型白名单，不新增 UI 框架或重量级依赖。

## 范围与设计

- 记住主窗口正常位置、大小和最大化；读取损坏文件或显示器消失时恢复到可见区域。连接页面不共享主工作台尺寸。持久化仅包含窗口几何信息。
- 保留已有单实例锁，增加覆盖启动聚焦行为的验证。托盘允许快速新建和退出，关闭行为可选直接退出或最小化；未设置时沿用直接退出。运行中任务与提醒须来自可信服务会话的必要摘要，不向桌面进程传 Key 或原始玩家数据。
- 固定官方 GitHub 仓库检查稳定 Release；下载后验证 SHA256，验证失败明确允许手动下载；按用户选择 A，首版只定位校验后的文件供用户手动安装，应用不自动启动安装程序。哈希只证明一致性，不代表开发者身份；尚未签名时说明 SmartScreen 与手工校验。
- 帮助内提供反馈链接和脱敏诊断（版本、服务地址、日志位置）。按 allowlist 生成，不含 Key、原始玩家数据或异常正文。
- 下载窗口按文件后缀提供 CSV、PNG、Markdown 的正确保存类型；现有 PDF 走打印。

## 检查点

1. 窗口状态与单实例测试，断开显示器和坏配置回退。
2. 托盘与可信 IPC：窗口销毁、服务切换、退出、没有托盘支持等边界测试。
3. 更新链：稳定版本/版本比较、固定来源、下载限制、哈希不匹配、断网和手动安装，不自动执行安装程序。
4. 反馈与诊断：账户、服务地址、Key 和玩家数据脱敏验证。
5. 完整 npm test、npm run build、真实 Electron 启动和打包安装烟测；记录签名情况和结果。未购买证书、未发布 Release。
